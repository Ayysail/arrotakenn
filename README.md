# Arrotaken Project Assets & Web Resources

Welcome! 👋

This repository is a shared collection of **webpages, images, assets, JSON files, APIs, and other resources** used across my projects.

I'm **Arrotaken**, and I use things in this repository for various projects, including:

* 🌐 Websites
* 🧩 Browser extensions
* 🛠️ Tools and utilities
* 📦 Other projects and experiments
* 📁 Shared assets and data

## Why is this repository here?

A lot of my projects need somewhere to host files or resources that they can access online. Rather than having everything spread across different places, this repository acts as a central home for them.

**If you arrived here because a browser extension or another project told you that it needed a link from this repository, that's probably why you're here.** 😄

## What's inside?

There's a bit of everything. You may find:

* HTML webpages
* Images and other media
* CSS, JavaScript, and other assets
* JSON files
* Data used by projects
* APIs
* Experimental or unfinished things
* Files that are only intended to be used by one of my projects

Because this repository serves multiple projects, **the directory structure may not always make perfect sense if you're just browsing it.**

## Is this meant to be browsed?

Not really.

This repository is primarily intended to be **used by my projects**, rather than read or explored like a normal website or software project.

That said, you're welcome to look around if you're curious. You might find something interesting. 👀

## APIs

There may also be APIs or API-like endpoints in this repository that aren't officially documented.

If you discover one and figure out how it works, **feel free to use it** where appropriate.

Just keep in mind that undocumented APIs may:

* Change without notice
* Be removed
* Stop working
* Have undocumented limitations
* Not be intended for production use

So use them at your own risk.

## A note about stability

Since this repository supports many different projects, **files and endpoints may change at any time**.

Something that works today might not work tomorrow, especially if it belongs to an experimental project.

If a particular project depends on something here, the project itself should generally be considered the best source of information about how that resource is supposed to be used.

## Have fun!

If you somehow ended up here while looking for something else, welcome anyway. 😄

Feel free to browse around, experiment, and see what you can find.

— **Arrotaken**
